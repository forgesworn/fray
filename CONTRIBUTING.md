# Contributing

Fray grows from real game integrations. Describe the consumer and behaviour a change supports, and keep game rules and simulation outside the transport.

Contributions are offered under the repository's MIT licence. By submitting a contribution, confirm that you have the right to provide it under those terms. No copyright assignment or separate contributor licence agreement is required. Preserve upstream licence and provenance notices.

Run the workspace tests and formatting check. Protocol changes need an explicit compatibility description and valid/invalid fixtures; package versions and wire versions are separate. Preserve namespace isolation and authenticated peer admission. Document limits and failures accurately, including what a local test does not prove.

Keep implementation changes reviewable. Do not include secrets, personal names or absolute local paths in commits or documentation. Do not weaken security guarantees to make an integration pass.
